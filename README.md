# Corner-Grocer-CS-210-Project-3-
Uses a file (a list of items sold that day) creates a back-up file, then shows the user a menu of choices to either (1) find the number of times one item appears in the file, or (2) print a list of the unique items with their frequencies, or (3) print a list of the unique items with their frequencies in histogram format, or (4) Quit program.
